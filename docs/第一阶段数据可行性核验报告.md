# 香港商业用电预测与高温风险分析｜第一阶段数据可行性核验报告

**有条件通过。** 2025年商业本地用电和总部站气温可按香港自然月对齐。两个历史刊期足以复核用电整数值，但逐月首发与修订轨迹仍缺证据。

## 样本和数据字典

2026-11-26（香港）在用户选定的 HK project 空目录初始化本地 Git。初始无 AGENTS.md、README 或计划文件。本轮现金支出 HK$0。

- [统计处表915-91201](https://www.censtatd.gov.hk/en/web_table.html?id=915-91201)：以表单字段 query 向 [POST 接口](https://www.censtatd.gov.hk/api/post.php) 提交下列 JSON。返回 9,272 字节、26 行，含系统附加的合计和年频行。只保存12条原字段月记录。period 为原始年月，freq=M，USER_TYPE=2、USER_TYPEDesc=Commercial，sv=ELEC_LOCAL，svDesc=Terajoule，figure 为原精度 TJ。口径排除电力企业自用、损耗与输往内地的电量。供电资料来自中电及港灯。

        {"cv":{"USER_TYPE":["2"]},"sv":{"ELEC_LOCAL":["Raw_Tjou_n"]},"period":{"start":"202501","end":"202512"},"id":"915-91201","lang":"en"}

- [天文台总部站 CSV](https://data.weather.gov.hk/weatherAPI/opendata/opendata.php?dataType=CLMTEMP&rformat=csv&station=HKO&year=2025)：年、月、日组成当地观测日期，Value 为日平均气温（°C），完整性 C 为完整。全年365个唯一有效日期，数值均可解析，无缺测，无插补。按观测年月汇总后可与用电月份一对一连接。
- 香港政府统计处《统计月刊》表7.3，按年、月和 Commercial 列读取整数 TJ。[2026年5月刊](https://www.censtatd.gov.hk/en/data/stat_report/product/B1010002/att/B10100022026MM05B0100.pdf)及[6月刊](https://www.censtatd.gov.hk/en/data/stat_report/product/B1010002/att/B10100022026MM06B0100.pdf)只读取在线表格摘录，整刊本地存储均为0字节。

## 第二阶段的证据目标

建议核查2015年1月至2025年12月连续132个月，以保留至少120个同口径可比月为目标。需检查两家电力公司和商业分类口径变更、月度发布滞后、历史快照及修订，补齐气温同期覆盖和预测日可得的天气情景依据。严格滚动回测须先重建每个预测时点可见的数据；目前只能验证结构、对账及自然月连接。完整历史长度、点预测误差和80%区间覆盖能力均待验证。

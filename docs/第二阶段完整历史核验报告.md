**有条件通过。** 截至2026-11-26，当前发布版本可组成201501–202512共132个连续自然月，超过预设的120个月数量目标。逐月首发版本与分类沿革仍有证据缺口。

## 来源与口径

[统计处 API](https://www.censtatd.gov.hk/api/post.php) 使用第一阶段报告中的 POST 参数，将 start 改为 201501，end 为 202512。返回原件含月度合计与年频行。筛选 freq=M、USER_TYPE=2、USER_TYPEDesc=Commercial、sv=ELEC_LOCAL、svDesc=Terajoule。统计处表注指明电力来自中电和港灯，本地消费排除电企自用、损耗和输往内地的电量。全窗字段一致，当前表注未指出断点。未取得两家电企逐年用户重分类或追溯修订记录，故132个月是按现行定义可对齐的候选样本，跨年分类稳定性仍待独立证实。

[天文台日平均气温 API（2015年示例）](https://data.weather.gov.hk/weatherAPI/opendata/opendata.php?dataType=CLMTEMP&rformat=csv&station=HKO&year=2015) 按年取得2015–2024年；2025年沿用本项目第一阶段同站原件。以年月日核对日历并拒绝重复日期，再按月计数。资料归属香港特区政府、政府统计处及香港天文台，使用及转载条件见[统计处告示](https://www.censtatd.gov.hk/en/page_31.html)与[开放数据平台条款](https://data.gov.hk/en/terms-and-conditions)。

## 版本与预测时点

观测年月与取得日分别记录。所有历史月份均取自当前统计表，查询时间不能用作首发日期。第一阶段的2026年5、6月刊只证实相应日期已有整数版。按官方档案接口以表号、20150101至20251231查询文件目录，返回 file-count=0；用英文全序列 CSV 地址查版本返回 HTTP 404。这些结果只覆盖此次查询，无法据此认定档案不存在。逐月发布滞后、修订日期及历史小数值仍未知。严格滚动回测须用有日期的月刊、历史表号或版本快照逐期重建，不能把当前值回填到过去的预测时点。[档案接口说明](https://data.gov.hk/en/help/api-spec)

常年情景有可定年的依据：天文台于2021-02-04发布1991–2020常年值，此前应核对当时适用的1981–2010版本。偏热情景可定义为预测日前历史同月温度的上分位数；本窗每个历月最多11次观测，早期更少，分位数阈值仍需足够长的先验基准期。天文台季节展望覆盖三个月，只能作偏热背景。月表中的目标月实测均温仅适合事后分析，不能充作事前天气输入。[常年值公告](https://www.hko.gov.hk/en/Whats-New/105637/1991-2020-Climatological-Normals-for-Hong-Kong) · [季节展望及实况](https://www.hko.gov.hk/en/wxinfo/season/fcvsobs_seasonal.htm)

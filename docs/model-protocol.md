# 模型比较与预测协议

2026-11-28，在查看此次扩展数据的2026年需求和回测得分前确定以下规则。本轮目标是检验较长历史和日尺度高温指标能否改善下一完整自然月的商业用电预测。

## 时间、口径与留出

目标单位为 TJ，按香港自然月键连接。每次预测目标月 t 时仅使用观测月不晚于 t−3 的需求和天气，区间校准也采用同一截止。此处假设发布滞后；实际逐期可得版本仍需核验。固定窗口以2015-01为训练资料起点，扩展窗口使用两来源的共同历史（可用时）。训练起点始终固定，各月按当时截止扩大训练集。月用电为单一商业本地用电记录；零、负值、重复年月或非法日期导致报错。天气缺值保留，只有同一个月每一天均有有效观测才汇总对应字段。日数按实际月长。

首次拟合至少用5个目标历月的有效历史同月，且当月预测必须有相应输入。单一候选在两训练窗口均尝试。以2020-01至2022-10验证期共同可评月份的月度 MAE 最小者作主模型（至少24个月）；截止到10月可保证第一个2023年预测已经看得到选择依据。样本不足的候选不参加选择，如共同交集不足24个月则终止。精确平手优先简单候选、固定窗口。2023–2025年仅作延续研究的诊断；2026年已公布月份作为本轮新留出，模型选定后不依据这些结果改参数。每月随时间更新训练资料；每个留出月使用其之前按上述规则可见的真实需求。分别披露各模型实际样本数、共同月份比较、偏热分组。比较所用年月存入逐月文件。

## 候选模型

- seasonal_naive 使用上年同月需求总量。
- smooth 将各年同月需求除以当月天数后按年指数平滑，平滑系数固定为0.25，首个有效同月初始化。
- linear 同样平滑日均需求，另用全部训练月份在各自历月内去均值后的日均需求、月均温做一元最小二乘，估算日均 TJ 对 °C 的局部响应。每个历史同月的日均需求先扣除天气响应，平滑后再加情景天气响应，最后乘目标月天数。
- heat_ridge 改用三个从日气温得出的特征：日均温高于24°C的正温差之月平均（°C）、日最低温达到28°C的日数占比、日最高温达到33°C的日数占比。先按历月去均值，再按训练样本的标准差缩放，固定岭惩罚系数 0.10（目标函数为平均平方误差加 0.10 倍标准化斜率平方和）；无训练方差的列斜率为零。月均温只用于排列情景。阈值用于本次实验，只有行政定义和业务含义均经另行核对后才可用作官方风险指标。湿度不作此次选模条件。

## 情景、区间与评价

以同一训练窗口内、同一历月、最近至多30个完整历史年份形成天气样本，保持每个历史月各特征的配对。主点预测为对这些历史天气逐个预测后取均值。常年情景采用月均温排名的经验第50百分位所对应的整套天气，偏热情景采用第80百分位；样本少时两者可能接近。分位用最近秩 ceil(p × n)。这些属于经验情景。偏热月事后诊断以实测月均温严格超过预测时的第80百分位判定，跨模型统一使用固定2015起的完整同月均温。季节基准与简单平滑给各情景相同的需求值；同时列出验证期得分最高的含天气候选，只用于解释天气情景敏感性。

目标覆盖80%的预测区间以同模型、同窗口历史滚动预测的绝对误差构建，最近至多60个已可见误差，至少12个才公布区间。采用排序索引 ceil(0.8 × (n+1))，下界截于零。报告覆盖率、平均宽度及可评月份数，不假设覆盖率必达80%。MAE 单位 TJ，WAPE 为绝对误差之和除以实际用电量之和。新留出月份数及偏热子集偏小时避免稳定性和因果结论。

2026年12月的实际预测以2026-11-28为出具日，使用截至2026年9月且已实际取得的观测，单独记录最后使用月份；若最近数据不足，将明确披露。复现命令为 node scripts/heat-backtest.mjs。结果位于 data/next/scores.json、predictions.csv 和 future.json。
